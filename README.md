# 群英大富翁

以《大富翁8》為主軸的網頁大富翁，融合四款遊戲的核心系統：

| 來源 | 原作重點 | 本作的做法 |
| --- | --- | --- |
| **大富翁8**（主軸） | 環狀地圖買地、加蓋 5 層建築、收過路費；擲骰前使用卡片（均貧、查稅、怪獸、購地、換地、烏龜、轉向、停留、遙控骰子、路障……）；神明附身（財神、福神、土地公、天使、窮神、衰神、惡魔）；卡片屋用點券買卡 | 地產 0～5 層（空地→摩天樓）、23 種機會卡、7 位神明隨機出現在地圖上、卡片屋、點券格、命運與新聞格 |
| **Dokapon Kingdom** | 職業（戰士/魔法師/盜賊起始，精通後解鎖進階職業）；戰鬥採猜拳式指令：攻擊被防禦減半、重擊會被反擊反彈、魔法被魔防削弱；職業有戰鬥技能與場上被動（戰士隨機攻擊提升、魔法師一回合施放兩次魔法、盜賊經過玩家時扒竊） | 6 種職業＋進階「勇者」，等級與經驗值、職業精通、魔物巢穴、玩家同格決鬥（勝者奪取現金或手牌）、敗者住院 |
| **Culdcept** | 開局前構築牌組（書）、每回合抽牌；用生物卡佔領土地；同屬性土地形成連鎖提高過路費；生物與土地屬性相同時獲得「地形 HP 加成」；停在敵地可用生物＋道具侵略奪地 | 20 張牌組構築（同名最多 3 張）、18 種生物／6 種道具／8 種法術、守護獸、屬性連鎖、先制／穿透／再生／反射等能力、侵略戰奪地（含建築） |
| **Fortune Street** | 地圖分區（district），每區有股票，股價隨區內店價上漲；有人在區內付費時股東分紅；收集四種花色回到銀行「升遷」領薪水；可用 5 倍價格強制收購店面；在銀行可投資店面 | 6 個商圈各有股票與走勢圖、股利分紅、大量買賣推動股價、♠♥♦♣ 升遷薪水、5 倍收購、銀行投資加蓋、總資產達標並回到銀行獲勝 |

> 各系統為參考原作概念後重新設計的數值與規則，並非原作的精確規則。

## 畫面

仿《大富翁8》的介面：

- 等角 2.5D 城市地圖（Canvas 繪製）：蜿蜒道路、六角形事件踩鈕、路旁地產會從平房一路長成摩天樓、銀行／醫院／神殿等地標、樹木與池塘。
- 紙片人風格的角色在路上一格一格跳著走，鏡頭跟隨目前角色；可拖曳、滾輪或雙指縮放。
- 左上日期欄（每回合一天）、上方訊息列、右上所有玩家頭像與現金。
- 左下目前角色大頭像與現金／資產／點券／HP／花色；中間是手牌；右下是大顆擲骰按鈕與股市、訊息、視角、選單按鈕。
- 米色面板＋咖啡色粗框的卡通對話框、大骰子動畫、回合橫幅、金錢變化飄字與金幣噴發。
- 角色是紙片人立牌；建築有光影漸層、投影、窗戶反光、屋頂水塔與天線；天空有飄動的雲、池塘有睡蓮。
- 效能：地面與道路預先繪製在離屏畫布，emoji 與立牌快取成小圖，每幀只畫會動的東西。

## 存檔

- **自動存檔**：每個回合開始時自動存檔，關掉網頁後在標題畫面按「▶ 繼續上次的遊戲」就能接著玩。
- **手動存檔**：遊戲中「☰ 選單 → 💾 存檔」，有 3 個欄位；「📂 讀取存檔」可讀自動存檔或任一欄位。
- **存檔碼**：可匯出一段 `RG1:` 開頭的文字（或下載 .json 檔），在別的瀏覽器／電腦「匯入」就能繼續。
- 存檔記錄的是「該回合開始時」的狀態，存在瀏覽器本機（localStorage）；清除瀏覽器資料會一併清掉，重要進度請用存檔碼備份。

## 怎麼玩

直接用瀏覽器開啟 `index.html` 即可（不需要安裝或建置）。

1. 開局畫面設定 2～4 名玩家：真人或電腦、角色、職業、牌組（可用預組或自己構築 20 張）。
2. 每回合：抽 1 張卡 → 擲骰前可使用法術／機會卡（魔法師可用 2 張）→ 擲骰移動 → 觸發停留的格子 → 與同格玩家決鬥。
3. 總資產（現金＋地產價值＋股票市值）達到目標並回到銀行就獲勝；到回合上限時資產最高者獲勝。

遊戲內「規則說明」有完整規則。

### 系統之間的連動

- **守護獸 vs. 收購**：沒有守護獸的地可被 5 倍收購、購地卡、換地卡奪走；派了守護獸就免疫這些，但會被生物侵略。
- **過路費** = 基本 × 商圈加成（Fortune Street）× 屬性連鎖（Culdcept）× 守護獸加成 × 神明／職業加成（大富翁8／Dokapon）。
- **職業影響卡牌與經濟**：魔法師每回合可用 2 張卡、盜賊扒竊手牌、煉金術士股利加成、忍者侵略先制、戰士鬥志提升生物 ST。
- **加蓋帶動股價**：地產價值上升會推高該商圈股價，股東都受益。

## 專案結構

```
index.html          入口
css/style.css       樣式
js/util.js          共用工具
js/data/            地圖、卡片、職業、魔物、神明、事件資料
js/engine/          遊戲引擎（回合、經濟、戰鬥、卡片效果、電腦 AI、存檔），不依賴 DOM
js/ui/world.js      等角地圖繪製（道路、建築、角色、鏡頭）
js/ui/saves.js      存檔欄位、讀檔、存檔碼匯出匯入
js/ui/              HUD、對話框、開局設定與牌組編輯器
tools/simulate.js   無介面模擬：讓電腦玩家自動對戰，用來測試規則與平衡
```

用 Node.js 跑模擬（例如 50 局，最後會再跑一次存檔→讀檔→跑完整局的測試）：

```
node tools/simulate.js 50
```
